# SiteFlow - NKRN Technologies

Two React/TypeScript/Vite demonstration apps in one repository.

- apps/portfolio: generic public demo with fictional data.
- apps/meridium: Meridium-branded concept using fictional data only; restrict sharing until client approval.

Local commands: npm install; npm run dev:portfolio; npm run dev:meridium.

Two Vercel projects should point to root directories apps/portfolio and apps/meridium (Vite, build npm run build, dist output). Check commercial hosting entitlement before deployment. These are demos: no real SMS, AI, authentication, backend, or offline sync. Proposed NKRN colors: Cyan Navy #092742, Ghost White #F8F8FF, Coral #FF8058 (accent unapproved).
