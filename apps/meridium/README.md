# SiteFlow Meridium Demo v0.3

Private Meridium-branded concept. All project, employee and operational data are fictional examples, not verified Meridium records.

## Run locally

```bash
npm install
npm run dev
```

## Scope

Interactive React + Vite + TypeScript UI. Demonstrates dashboard, daily scheduling, editable tasks, project/team lists, simulated messaging, search/filter, dark mode, shortcuts, browser-local draft saving, FAQ and legal placeholders.

**Not implemented:** authentication, actual SMS/WhatsApp delivery, backend, AI, real offline sync, live notifications, production security, legal approval. The language selector stores preference but does not translate all UI text.

All records are sample data. No client data has been verified. Do not treat this demo as production-ready.

## Brand

SiteFlow is an NKRN Technologies product. Meridium logo is displayed as a separate client brand; the original supplied logo is used rather than an AI reinterpretation.

## Legal
